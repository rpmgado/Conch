## 文件传输

原实现先清空目标，再尝试读取源；源不可读时会留下 0 字节目标。现在先打开源，把内容写到目标同目录的独占临时文件，完成读写及校验后再替换。下载使用本机重命名提交；上传为兼容标准 SFTP v3，先把旧文件改名为备份，再提交新文件，失败时尝试恢复。第一次改名之前，还会写入恢复记录，保存目标、临时文件和备份之间的对应关系。无法恢复或无法清理备份时，错误信息会给出恢复路径；进程崩溃后也能按恢复记录定位原文件。

续传会逐块比对已有前缀；等长文件也要比较内容。不匹配时从头写临时文件，不把错误前缀接到新内容上。同一次 App 运行内，失败或取消后的重试可复用临时文件；已排队的写请求会结束后再报告取消，避免旧写请求与重试并发。相同目标的传输在进程内互斥。

提交前检查源大小／修改时间是否变化，上传还检查目标是否被修改。目录符号链接不自动递归，避免越出用户选择范围或循环；不安全的远端文件名会被拒绝。

验证包含：源权限错误保留旧文件、上传与下载的等长异内容／错误前缀、中途取消保留旧版本、取消后校验续传、既有权限、常规目录传输和真实 lrzsz。

边界：这不是整个目录的事务。远端备份／替换可能使目标路径短暂不可见；连接在提交阶段中断时应按错误信息检查目标和备份。覆盖需要目录写权限；只处理 SFTP 提供的 POSIX 权限和 UID/GID，ACL、扩展属性及硬链接关系不保证保留。实时持续变化的文件应先取得稳定副本。传输队列和临时文件登记不跨 App 重启恢复；清除传输记录不会自动删除磁盘上的临时文件。

## 密码保护

当系统不能执行身份验证时，拒绝读取保存的密码。取消验证和验证不可用都会提示改为手动输入。保留已有的 5 分钟授权宽限及自动重连行为，验证开关的说明已更新。正式版通过编译开关禁用测试钩子；自动信任主机、模拟身份验证等功能仅存在于独立的 Conch Tests 构建，使用独立应用标识和钥匙串服务。

## 界面

- 会话编辑器先显示连接与认证信息，再显示名称和分组；高级选项可折叠，已有高级配置会自动展开。
- SSH、Telnet、串口具有各自的辅助功能名称；已检查键盘 Tab 顺序和空格展开高级设置。
- 文件面板明确标注本地和远端、当前选择数量与完整路径提示；可展开为左右对照模式，复用原连接和传输队列。覆盖确认、文件选择等对话框附着于当前面板；关闭展开视图后恢复终端键盘焦点。
- 生产环境文字提示不再依赖主题。三套主题保留原风格。
- 侧边栏新用户默认稍宽，辅助文字增大；外观设置提供紧凑模式。已有窗口宽度偏好保留。
- 工具栏“文件”“监控”增加文字；主题卡片缩小，说明左对齐，设置窗口能显示更多常用选项。
- 测试实例不读取真实快速连接历史，避免测试截图混入个人服务器信息。

## 开源准备

- Rust 固定到 1.99.1；Cargo 和 SwiftPM 强制使用锁文件。
- 新增 `scripts/ci.sh` 和 GitHub Actions。官方 `xcode-27` Arm64 镜像、Xcode 27.2；Actions 固定到提交 SHA，仓库权限只读。
- CI 包含构建、Swift 模型测试、Rust 单元测试、本机核心场景、许可证材料和签名／架构检查。桌面 UI 测试另外运行，不假装在无桌面的 CI 上通过。
- 新增贡献说明、安全报告方式、Issue 和 PR 模板、CHANGELOG、发布步骤。
- 根据锁文件生成 227 个运行时及构建时依赖的许可材料；App 内包含自身 MIT 许可证和第三方版权／许可文本。
- README 说明了安装包签名、公证以及同步与传输的限制。
