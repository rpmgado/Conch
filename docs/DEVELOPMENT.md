# Conch 开发文档

[← 返回中文 README](../README.zh-CN.md)

这份文档写给想改代码、自己打包，或者想了解实现细节的人。安装和使用说明见 [中文 README](../README.zh-CN.md)。

## 正式版与测试版

正式 App 忽略测试环境变量。运行桌面回归前先执行 `CONCH_TESTING=1 scripts/build.sh`，生成独立的 `build/Conch-Test.app`；然后运行 `scripts/app-e2e.sh`。测试版使用独立应用标识和钥匙串服务，不能作为正式安装包分发。

## 构建

```bash
scripts/build.sh            # Rust 内核 → 生成 Swift 绑定 → SwiftPM 编译 → build/Conch.app
open build/Conch.app
```

依赖：rustup 的官方 Rust 工具链、Swift 工具链（Xcode 或 Command Line Tools 都行）。rustup 这样装，装在 `~/.cargo` 和 `~/.rustup`，不改终端设置，和 Homebrew 的 Rust 互不影响；构建时用哪个版本写在 `core/rust-toolchain.toml`（稳定版），第一次构建时 rustup 会自动装好：

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y --no-modify-path --default-toolchain none
```

编译中间产物放在项目内的 `.build-cache/`，已加入 Git 忽略并随项目一起搬迁。可以用 `CONCH_BUILD_CACHE` 换位置。

## 打包和发布

### 打包

```bash
scripts/package.sh          # 编译 release 版，签名、检查，打出安装包和磁盘映像
open build/Conch-0.4.0.pkg  # 安装向导：继续 → 安装（输入开机密码）→ 完成
```

`scripts/package.sh` 打出两个文件，装的是同一个 App，选一个发给别人：

| 文件 | 怎么装 |
|---|---|
| `build/Conch-0.4.0.pkg`（推荐） | 安装向导：介绍 → 安装 → 摘要，装进“应用程序”文件夹 |
| `build/Conch-0.4.0.dmg` | 磁盘映像：打开后把 Conch 拖进旁边的“应用程序” |

- 装好后，在程序坞的“App”（macOS 15 及以前叫“启动台”）、“应用程序”文件夹和聚焦搜索里都能找到 Conch。
- 安装包固定装到 `/Applications/Conch.app`，不会跑去升级别处（比如项目 `build` 目录里）的同一个 App。“应用程序”里原来的 Conch（包括标识不同的 0.3 旧版）会被直接覆盖；那里要是别的同名软件，安装向导会停下来说明原因，不去覆盖它。
- 升级：直接装新版本的安装包，会话和设置都保留。
- 卸载：把“应用程序”里的 Conch 拖到废纸篓。会话、分组和快捷命令在 `~/Library/Application Support/Conch`，设置在 `~/Library/Preferences/com.conch.gado.plist`，密码在钥匙串里（服务名 `Conch`）；删掉 App 不会删掉这些，想彻底清掉要另外删。
- 只有 Apple 芯片（arm64）版本，Intel 的 Mac 上安装向导会直接提示装不了。最低系统是 macOS 14，所有 Apple 芯片的 Mac 都能升级到；目前只在 macOS 27 上实际跑过，更老的系统做了静态检查（见下面的“验证记录”）。
- 第一次连局域网里的机器时，系统会问是否允许 Conch 访问本地网络，要点“允许”，否则连不上；点错了到“系统设置 → 隐私与安全性 → 本地网络”里打开。
- 0.4 起 App 标识（Bundle ID）从 `dev.conch.prototype` 换成了 `com.conch.gado`。第一次打开新版本时会自动把旧版的设置搬过来；本地网络、钥匙串的授权要重新允许一次。

### 签名和公证（让别人双击就能装）

没有 Apple 开发者签名的安装包（现在就是这样），在别人的 Mac 上会被系统拦下。对方第一次双击安装包，会看到“Apple 无法验证……是否包含恶意软件”，要这样打开：

1. 在提示框里点“完成”；
2. 打开“系统设置 → 隐私与安全性”，拉到下面，在“已阻止……”那一行点“仍要打开”，输入开机密码；
3. 再点一次“仍要打开”，安装向导就出来了。

用安装包装好后，打开 Conch 不会再被拦。用磁盘映像的话，拖进“应用程序”后第一次打开 Conch 时，还要走一遍上面的步骤。

想让别人双击就能装，要用 Apple 开发者账号（Apple Developer Program，每年 99 美元，国内 688 元）的证书签名，再交给 Apple 公证。打包脚本已经接好了，有账号后做一次准备：

1. 在 developer.apple.com 的 Certificates 页面创建两个证书：Developer ID Application（签 App 和磁盘映像）和 Developer ID Installer（签安装包），下载后双击装进“登录”钥匙串。创建时要上传的 CSR 文件，在“钥匙串访问”（用聚焦搜索打开）的“证书助理 → 从证书颁发机构请求证书”里生成。
2. 在 account.apple.com 生成一个 App 专用密码，然后把公证用的账号存进钥匙串（会提示输入这个密码）：

   ```bash
   xcrun notarytool store-credentials conch-notary --apple-id 你的AppleID --team-id 你的TeamID
   ```

3. 以后这样打包。脚本会自动找到证书签名，交给 Apple 公证（每个文件几分钟），再把公证结果钉进 App、安装包和磁盘映像，离线也能通过检查：

   ```bash
   CONCH_NOTARY_PROFILE=conch-notary scripts/package.sh
   ```

钥匙串里有好几个证书时，用 `CONCH_SIGN_IDENTITY`、`CONCH_INSTALLER_IDENTITY` 指定用哪个。

## 测试

```bash
scripts/test-sshd.sh start
scripts/core-tests.sh          # 加 --quick 跳过吞吐和流控
scripts/app-tests.sh
scripts/build.sh && scripts/app-e2e.sh
```

App 的测试钩子只在设置了 `CONCH_DATA_DIR` 时生效（测试数据和真实数据完全隔开），用法见 `app/Sources/Conch/TestHooks.swift`。

点击、拖动、滚轮、按键这类交互用测试脚本（`CONCH_TEST_SCRIPT`，见 `app/Sources/Conch/TestScript.swift`）：它往 App 自己的事件队列里放鼠标和键盘事件，和用户操作走同一条路（窗口找点到的视图、交出键盘焦点、输入法），每一步之后把焦点、分屏结构、标签栏位置等写一行 JSON。`app-e2e.sh` 最后一段用它测键盘焦点、拖动分屏、标签栏滚动和本机文件栏；这一段用 `open` 启动 App，Conch 会到前台几秒，跑的时候别动鼠标键盘。

手边没有服务器的话，先在本机起几个测试服务器：

```bash
scripts/test-sshd.sh start  # 2222 现代算法 / 2223 只开老算法 / 2224 模拟服务器（密码、二次验证、GBK、rz/sz）/ 2325 模拟 Telnet 设备
scripts/test-sshd.sh stop
```

用户名填你的 macOS 用户名，私钥用脚本打印出来的路径；模拟服务器的用户名和密码见脚本开头。

## 架构要点

```
远端输出 → russh 读循环（tokio）→ 流控记账 → SessionDelegate.onOutput（内核线程）
        → 标签页的串行队列：交给 SwiftTerm 解析、写日志 → ack 归还额度
键盘输入 → TerminalViewDelegate.send → SshSession.write（只是投递消息，线程安全）→ 写循环
跳板机   → 第 n 跳的 channel_open_direct_tcpip → 在这条通道上跑第 n+1 跳的 SSH（connect_stream）
```

- 密码、口令不放在连接配置里：内核需要时调 `request_secret`，界面先查标签页的内存、再查钥匙串，都没有才弹窗。只在真正用到时读钥匙串，秘密也不在各层之间传来传去
- 连接结束时内核报告是不是“意外断线”（`lost`）：服务器发了退出码或主动关闭通道就不是，连接本身断了才是。自动重连只看这个标志，用户 `exit` 不会被重连
- 连接超时只算等网络的时间，用户看主机指纹、输密码的时间不算
- 每个标签页的终端都挂在窗口里，只显示选中的那个；后台标签页照样接收输出、跟着窗口调整尺寸
- SSH、Telnet、串口在界面层是同一个 `TerminalConnection` 接口（写入、改尺寸、流控、关闭），终端、日志、编码、自动重连都共用；文件面板、转发、监控只对 SSH 打开
- 分屏：每个标签页是一棵分屏树，终端区域自己排版、画分隔线和分屏标题栏（没用 NSSplitView），拖动分隔缝、拖标题栏换位置都直接改分屏树，不经过 SwiftUI
- 键盘焦点：GPU 绘制时 SwiftTerm 在终端上面盖了一层绘图视图，鼠标点到的是它，窗口不会自动把焦点交给终端。所以 `ConchTerminalView` 在鼠标按下时自己要焦点；以后换 SwiftTerm 版本也要留意这一点
- 刷新：每个终端的变化（标题、尺寸、状态）都会让整个窗口刷新一次。会话列表的状态（选中、搜索、折叠、哪些会话连着）单独放在 `SidebarState` 里，会话列表不观察整个窗口，只在这些变了时重画；会话多的时候这是卡不卡的关键
- 监控和远程执行在同一条 SSH 连接上另开 exec 通道；采集脚本用 `/bin/sh` 执行，不受用户登录 Shell（fish 等）影响
- 同步：每次修改前先看文件是不是被别处改过，改过就先读进来再在最新的内容上做这次修改，所以两台 Mac 同时改不会互相覆盖

## 开发备注

- 只装 Command Line Tools 也能构建和测试。新版 SDK 里 SwiftUI 的 `@State` 是宏，宏插件只随 Xcode 提供，所以界面状态都放在 `ObservableObject` 里；Swift Testing 的宏插件在 `plugins/testing` 子目录，`scripts/app-tests.sh` 会自动加上路径。装了 Xcode 就没有这些限制。
- Rust 用 rustup 的官方工具链，`core/rust-toolchain.toml` 固定为 1.99.1。不用 Homebrew 的 Rust：它的标准库按本机系统版本（macOS 27）编译，链接时会报 “built for newer macOS”，App 在老系统上可能打不开。所以 `build.sh` 找不到 rustup 时会直接停下，提示怎么装。
- `Package.swift` 用 `unsafeFlags` 链接 Rust 静态库，所以这个包只能作为根包构建。
- 没有证书时是 ad-hoc 签名（打开了 hardened runtime，和公证版的运行限制一样）：每次重新构建签名都会变，之后第一次读钥匙串里保存的密码时，系统会问是否允许，点“始终允许”即可；本地网络、文件夹的访问授权也可能要再允许一次。换成 Developer ID 签名后签名身份固定，就不会再反复问。
- 版本号改 `app/Info.plist` 里的 `CFBundleShortVersionString`；构建号由 `build.sh` 自动填成提交次数。

## 功能细节（按开发阶段）

### 阶段 0

- 主机密钥校验（兼容 `~/.ssh/known_hosts`）、老设备算法开关、xterm-256color、中文、OSC 52 剪贴板、Metal 渲染、流控（狂刷输出时 Ctrl+C 不卡）。

### 阶段 1

- **会话管理**：左边是会话列表，支持多级分组、搜索（名称 / 主机 / 用户 / 分组 / 备注）、右键菜单（连接、编辑、复制、移动到分组、删除、忘记密码）。双击或回车连接。会话存在 `~/Library/Application Support/Conch/sessions.json`，不含任何密码。
- **标签页**：一个窗口多个标签页，可以拖动排序；标签上显示连接状态、后台有新输出、正在记录日志。新标签页里可以快速连接，也列出最近用过的会话。⌘N 开新窗口。
- **快速连接**：直接输入 `user@host:端口`，或者整条 `ssh -p 2222 -i 私钥 -J 跳板机 user@host` 命令，或者 `~/.ssh/config` 里的别名（会按配置补全主机名、用户、私钥、跳板机）。连上以后可以“保存为会话”。
- **认证**：
  - 默认“自动”，和 ssh 命令一样依次试 ssh-agent、私钥文件、密码。也可以指定只用密码、私钥或 ssh-agent。
  - 支持 1Password / Secretive 这类自定义 agent socket（ssh_config 的 IdentityAgent）。
  - 密码和私钥口令在需要时才弹窗问，可以勾选“在钥匙串中记住”，连接成功后才写进钥匙串。钥匙串里的密码不对时会重新询问。
  - 密码按 `用户@主机:端口` 保存，同一台服务器的会话共用；私钥口令按私钥文件保存。
- **跳板机**：会话可以指定另一个会话当跳板机，跳板机自己还能再套跳板机（等同 `ssh -J a,b`）。每一跳单独认证、单独校验主机密钥。
- **堡垒机二次验证**：支持 keyboard-interactive。只开 PAM 的服务器自动用密码答第一问，动态口令弹窗输入；也支持“公钥 + 动态口令”这类多因素认证。
- **断线自动重连**：网络断开、服务器重启、保活超时时，按 1、2、4…30 秒的间隔自动重连（最多 20 次）。网络恢复或电脑睡眠唤醒时立刻重试。远端正常退出（`exit`）不会重连。断开后在终端里按回车也能重新连接。
- **会话日志**：每个会话可以设为连接后自动记录，也能随时用 ⌥⌘L 开关。默认存纯文本，去掉颜色并处理回车和退格，内容和屏幕上看到的一致；可以给每行加时间戳。也可以存原始输出。默认目录 `~/Library/Logs/Conch`。
- **配色和字体**：8 套配色（含“跟随系统”自动切换深浅色）、字体、字号（⌘+ / ⌘- / ⌘0）、光标样式、回滚行数（默认 1 万行），在设置（⌘,）里改，所有终端立即生效。
- **导入**：
  - `~/.ssh/config`：支持 Include、通配符默认值、ProxyJump，以及老写法 `ProxyCommand ssh -W`。
  - Xshell 的 .xsh 会话文件：可以选单个文件，也可以选整个 Sessions 文件夹，子文件夹会变成分组。Xshell 加密保存的密码不导入。

### 阶段 2

- **文件面板（SFTP）**：状态栏的文件夹按钮或 ⌥⌘F 打开，走的是同一条 SSH 连接（经过跳板机也一样）。
  - 浏览：地址栏可以直接输入路径；有“转到终端当前目录”按钮，需要远端 Shell 报告当前目录（OSC 7）。
  - 上传：从访达拖文件或文件夹进来。
  - 下载：双击文件下载到“下载”文件夹，也可以选目录下载；整个文件夹会连同子目录一起传。
  - 传输队列显示速度和进度。失败或取消的可以“续传”：从断开的地方接着传，不用重来。
  - 右键菜单：新建文件夹、重命名、改权限、删除（文件夹连同内容）、复制路径、在终端里 cd 过去。
- **rz / sz**：在远端执行 `sz 文件` 直接下载到“下载”文件夹，同名文件不会被覆盖；执行 `rz` 弹出窗口选要上传的文件。
  - 状态栏显示进度，可以取消，取消后终端恢复正常。
  - 协议用 zmodem2（MIT/Apache），不含 GPL 的 lrzsz 代码。单个文件上限 4 GB，这是 ZMODEM 协议本身的限制。
- **端口转发**：本地（-L）、远程（-R）、动态 SOCKS4/5 代理（-D）。
  - 可以在会话设置里配好，连上自动开启、重连后自动恢复；也可以在状态栏的“转发”面板（⌥⌘P）临时加，面板里能看到连接数和流量。
  - 导入 `~/.ssh/config` 时会带上 LocalForward / RemoteForward / DynamicForward。
- **字符编码**：会话设置里可以选 GBK/GB18030、Big5、Shift_JIS、EUC-JP、EUC-KR 等，输出和键盘输入都会转换，老服务器、网络设备不再乱码。rz/sz 不受编码影响。
- **同步输入**：⌥⌘I 打开后，在一个标签页里敲的键会同时发给这个窗口里所有连着的会话，窗口顶部有橙色提示。
- **撰写栏和快捷命令**：⌥⌘B 打开，先写好命令再发，可以发给当前会话或全部会话。快捷命令在设置里编辑，点一下就发。
- **终端里查找**：⌘F，支持区分大小写和正则；⌘G / ⇧⌘G 找下一个、上一个。
- **关键字高亮**：输出里的 error、failed、warning、ok 等词自动加颜色，关键字可以在设置里改。全屏程序（vim、top）里不加，日志文件里存的是原始内容。

### 阶段 3

- **Telnet 和串口**：会话编辑器顶上选协议（SSH / Telnet / 串口）。
  - Telnet：协商终端类型和窗口大小，字符编码、自动重连、会话日志和 SSH 一样可以用；状态栏会提醒“不加密”。快速连接里直接输入 `telnet 主机 端口` 也行。
  - 串口：从列表里选 USB 转串口设备（插上线后点刷新），设置波特率（1200～921600）、数据位、校验、停止位、流控（RTS/CTS 或 XON/XOFF）。拔线后会自动重新打开；设备被别的程序占用、找不到时有中文提示。
  - 从 Xshell 导入时 Telnet 会话一起导入；串口会话因为 Windows 的 COM 口在 Mac 上用不了，会提示在 Conch 里新建。
- **分屏**：⌘D 左右分、⇧⌘D 上下分，新分屏里再连一次同一个会话；会话列表右键“在右侧 / 下方分屏打开”可以把别的服务器放到旁边。
  - 拖分屏之间的缝调大小，双击平均分；有焦点的分屏有一圈强调色（环境色主题里是环境的颜色）。⌘] / ⌘[ 切换分屏，⇧⌘↩ 放大当前分屏（再按一次还原），⌘W 关闭当前分屏。
  - 状态栏、文件面板、监控、查找、菜单命令都跟着获得焦点的分屏走；同步输入会发给所有分屏。
- **服务器监控**：状态栏的仪表按钮或 ⌥⌘U 打开，右侧面板上方可以在“文件 / 监控”之间切换。
  - 每 3 秒在同一条 SSH 连接上另开一个通道采集一次，不占用终端，也不用再登录。显示 CPU（核数、负载）、内存和交换分区、网络收发速度、磁盘（百分比和 `df` 一致，快满时警告）、最占 CPU 的进程；CPU、内存、网络画最近 3 分钟的曲线，鼠标移上去看那一刻的数值。
  - 目前只支持 Linux；面板关着时不采集。堡垒机、网络设备不允许另开通道时会说明原因。
- **远程编辑**：文件面板里右键“用本机编辑器打开”，文件下载到本机用编辑器打开，每次保存自动传回服务器，覆盖时保留服务器上原来的权限。
  - 打开编辑之后服务器上的文件被别人改过，保存时会提醒，不会悄悄覆盖；可以选择用自己的版本覆盖，或者重新下载。
  - 默认按文件类型用默认应用；默认应用是终端这类“打开就执行”的，改用文本编辑。也可以在设置的“传输”里指定编辑器（VS Code、BBEdit……）。
- **会话同步**：设置 →“同步与安全”里选一个同步文件夹（iCloud 云盘，或者坚果云、群晖、飞牛的同步盘），会话列表、分组和快捷命令放进去，几台 Mac 选同一个文件夹就能共用。
  - 打开同步时本机的会话会并进去（两边各自导入的同一台服务器不会重复）。同步盘把更新传到本机后，App 会定期读取。会话库按最近共同版本合并字段；同字段冲突时保留本机操作，并在本机 `Sync Conflicts` 目录备份双方版本。普通同步盘不提供跨 Mac 的分布式事务。
  - 同步文件夹暂时打不开（移动硬盘、NAS 没连上）时先用本机留的那一份，会话列表底部显示提醒，等它回来自动合并；离线修改和删除通过本机 checkpoint 持久化，重启后也能恢复。
  - 保存的密码在各自的钥匙串里，信任过的主机也各自记录，都不会放进同步文件夹。
- **Touch ID 保护**：设置 →“同步与安全”里打开后，连接时要用钥匙串里保存的密码或私钥口令，会先要求 Touch ID 或 Mac 登录密码验证；验证一次 5 分钟内不再问，同时打开几个会话也只问一次。取消验证就改为手动输入密码。
- **lrzsz 兼容性**：用 Homebrew 装的真实 lrzsz 0.13.1 测过 sz 下载（单个、多个文件）、rz 上传和取消，见下面的验证结果。

### 界面改版

- **布局**：会话列表是左边浮起来的一张卡片（带搜索），右边上面是标签栏胶囊和工具按钮（分屏、文件、监控、外观主题），中间每个终端是一张圆角卡片，下面是撰写栏和状态栏胶囊。标题栏藏起来了，工具栏的空白处可以拖动窗口；会话列表、右侧面板的边缘可以拖动调宽度，⌃⌘S 收起会话列表。
- **三套主题**，随时切换：
  - **玻璃**：浅色、半透明，透出桌面，和系统界面一致；终端是白底卡片。
  - **石墨**：深色，窗口和终端连成一片，用图标的珊瑚色点缀。
  - **环境色**：浅色界面、深色终端卡片，按分组的环境标签给会话上色（见下）。

- **分组的环境标签**：会话列表里分组右键 →“环境”，标成生产、测试或设备；下级分组没设时跟着上级。标签存在会话列表里，打开会话同步时一起同步。环境色主题里：

  - 颜色之外都有文字，不只靠颜色区分。

### 修 bug 和优化（2026-11-10）

- **点终端打不了字**：打开文件面板、点过文件列表（或者会话列表、搜索框）之后，再点终端，键盘输入还是进了原来的列表，只有切换一下标签页才恢复。原因是 GPU 绘制时鼠标点到的是终端上面的绘图层，窗口不会因此把焦点交给终端；切换标签页会主动交，所以切过去再切回来就好了。现在点终端（左键、右键、中键）都会把焦点拿回来。
- **卡顿**：以前会话列表的每一行都跟着窗口刷新，终端每出一次提示符（改标题）、窗口每变一次大小，整棵会话树都要重建、每一行重画。会话列表现在只在自己的内容变了时才重画：300 个会话时，窗口每刷新一次从 15.5 毫秒降到约 1.2 毫秒。服务器文件列表排好序存着，不再每次重画都重新排；文件列表里的日期格式化器也不再每行新建。
- **标签栏**：标签多了先自动变窄（最窄 118 点，还看得清会话名），还放不下就左右滚动，鼠标滚轮上下滚也能翻；新开、切换的标签页自动滚到看得见的地方；放不下时右边多一个下拉按钮，列出所有标签页。
- **分屏**：分屏后每个分屏上面有一条标题栏（连接状态、会话名、放大、关闭），双击标题栏放大 / 还原。按住标题栏拖到另一个分屏的上下左右，就放到那一边；拖到正中间是互换位置；拖到标签栏变成单独的标签页（连接不断）。分屏之间的缝鼠标移上去会出现一个小把手，提示可以拖。
- **分屏排版没跟上**：终端区域靠一个“分屏结构签名”判断要不要重新排版，以前签名里只有分屏的顺序编号，换位置、平均分配之后编号不变，界面要等下一次别的变化才更新。现在签名里是每个分屏自己的编号和各层的比例，菜单里的“平均分配分屏大小”也因此点了马上生效。
- **右键菜单**：终端里右键有拷贝、粘贴、全选、查找、清屏、分屏、放大、移到新标签页、关闭分屏、重新连接、断开连接。
- **本机文件栏**：文件面板分上下两栏，上面是服务器，下面是本机，中间一条分隔条（“上传”“下载”两个按钮，上下拖动调两栏高度）。
  - 双击本机文件上传到服务器当前目录，双击服务器文件下载到本机那一栏的文件夹；两栏之间可以互相拖；右键菜单里也有。
  - 两栏都有“显示隐藏文件”的按钮（眼睛图标）。本机那一栏记住上次的文件夹，下载完的文件会自己出现（留意文件夹的变化）。
  - 要覆盖同名文件时先问一声；本机文件删除是移到废纸篓。
  - 面板标题栏上的电脑图标可以收起本机那一栏，收起时和以前一样：双击下载到“下载”文件夹。
